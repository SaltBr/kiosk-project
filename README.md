#kiosk-project
Java를 사용한 키오스크 과제입니다. 메뉴 숫자를 입력하여 메뉴를 담거나 삭제할 수 있습니다.

필수lvl1 - 도전lvl2까지 별도의 브랜치에 나뉘어 있습니다.

## 필수lvl1:
- 클래스 적용 없는 기본적인 키오스크
- 메뉴를 선택하면 해당 메뉴를 출력
- 0을 입력해 종료

## 필수lvl2:
- MenuItem 클래스 추가
- MenuItem으로 음식 항목 관리

## 필수lvl3:
- Kiosk 클래스 추가
- Kiosk에서 실행 기능 관리

## 필수lvl4:
- Menu 클래스 생성
- MenuItem을 잘못 활용하고 있습니다. 이 부분은 도전lvl2에서 수정됩니다.

## 필수lvl5:
- 캡슐화 적용

## 도전lvl1:
- 장바구니 및 구매하기 기능 추가
- 장바구니 내 메뉴가 있을 경우에만 장바구니 메뉴 출력

## 도전lvl2:
- enum으로 주문 활인 유형 관리
- 장바구니 출력을 람다와 스트림을 사용하도록 변경
- Menu 클래스의 전체적인 수정
